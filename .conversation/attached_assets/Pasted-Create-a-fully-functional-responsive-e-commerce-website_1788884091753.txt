Create a **fully functional, responsive e-commerce website** for a cute women’s clothing brand called **“Mimi & Moon.”**

### Brand & Design

* Cozy, cute, dreamy Nordic-storybook aesthetic.
* Original illustrations only — use clouds, stars, flowers, moons, bows, and soft decorative elements. **Do not use copyrighted characters or logos.**
* Colors: cream, dusty pink, sage green, dark brown.
* Fonts: Poppins or Nunito.
* Clean, polished, premium UI/UX with plenty of whitespace.
* Fully responsive on desktop, tablet, and mobile.

### Pages

Create:

* Home
* Shop
* Collections
* Product Details
* About
* Search
* Favorites/Wishlist
* Shopping Cart
* Checkout
* Order Confirmation

### Functionality

Make everything actually work:

* Product categories and filters
* Search products
* Sort by price, newest, and popularity
* Product image gallery
* Product size/color selection
* Quantity controls
* Add to Cart
* Remove/update cart items
* Wishlist/Favorites
* Cart item counter
* Persistent cart and wishlist using localStorage
* Checkout form with validation
* Order summary with subtotal, shipping, discount, and total
* Promo/discount code functionality
* Successful order confirmation page
* Navigation buttons must lead to the correct pages
* Product cards must open the correct product details
* Show clear empty states for empty cart/wishlist
* Add loading and error states where appropriate.

### Homepage

Include:

* Beautiful hero section with:
  **“Wear a little bit of magic.”**
* CTA buttons: **Shop Now** and **Explore Collections**
* Featured products
* New arrivals
* Popular collections
* Promotional banner
* Newsletter signup
* Footer with navigation and social links

### Products

Create realistic sample products with:

* Product name
* Price
* Images
* Description
* Available sizes
* Colors
* Category
* Rating
* Stock status

### Important UX Rules

* Buttons must be obvious and consistent.
* Never use buttons that do nothing.
* Show feedback after actions such as “Added to cart.”
* Prevent checkout when the cart is empty.
* Validate required fields.
* Make forms accessible.
* Keep navigation simple and intuitive.
* Use confirmation dialogs where deleting/removing something could be accidental.
* Make mobile navigation easy to use.

### Technical Requirements

* Build it as a real working web application, not a static design.
* Use clean, reusable components.
* Keep the code organized and maintainable.
* Use localStorage for cart, wishlist, and relevant user preferences.
* No broken links, placeholder buttons, or unfinished sections.
* Test every major user flow before finishing.

### Final Testing

Test the complete flow:

**Home → Shop → Product → Select size/color → Add to Cart → Cart → Checkout → Order Confirmation**

Also test:

**Search → Product → Wishlist**

and:

**Cart → Update quantity → Remove item → Correct total**

Fix any bugs, broken interactions, layout problems, or responsive issues before delivering the final website.
